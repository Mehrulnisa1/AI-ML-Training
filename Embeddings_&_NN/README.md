# Additional AI & Machine Learning Topics

# 16. Embeddings and Vector Representations

## 16.1 Embedding
An embedding is a numerical representation of data such as text, images, or audio in the form of a vector. It converts complex information into numbers so machine learning models can understand similarities and relationships between data points.

## 16.2 Static Embedding
Static embeddings assign a fixed vector representation to each word, regardless of the context in which it appears. For example, the word "bank" has the same embedding in both "river bank" and "bank account".

Examples include Word2Vec, GloVe, and FastText.

## 16.3 Contextual Embedding
Contextual embeddings generate word representations based on the surrounding words and the context in which a word is used. Therefore, the same word can have different vector representations depending on its meaning in a sentence.

Examples include embeddings generated by BERT and other Transformer-based models.

## 16.4 Vector
A vector is an ordered collection of numerical values representing information in a mathematical space. In machine learning, vectors are commonly used to represent text, images, and other data.

## 16.5 Vector Database
A vector database is a database designed to store, manage, and retrieve high-dimensional vector embeddings. It helps applications find semantically similar information rather than relying only on exact keyword matches.

Examples include Pinecone, Chroma, Weaviate, and Milvus.

## 16.6 Vector Search
Vector search is a technique used to find vectors that are similar to a given query vector. It uses similarity or distance measures such as cosine similarity, Euclidean distance, and dot product to identify relevant results.

## 16.7 Similarity Search
Similarity search compares vector representations to find data points that are closest to a query. It is widely used in semantic search, recommendation systems, image retrieval, and Retrieval-Augmented Generation (RAG).

# 17. Neural Network Layers

## 17.1 Neural Network Layer
A neural network layer is a group of interconnected artificial neurons that process information and pass their outputs to the next layer. Each layer learns or transforms particular representations of the input data.

## 17.2 Input Layer
The input layer receives the original features or data supplied to the neural network. It passes this information to the hidden layers for processing.

## 17.3 Hidden Layer
Hidden layers process input information using weights, biases, and activation functions. Multiple hidden layers allow a network to learn increasingly complex patterns.

## 17.4 Output Layer
The output layer produces the final result or prediction of the neural network. Its structure and activation function depend on the problem being solved.

# 18. Next-Token Prediction

## 18.1 Next-Token Prediction
Next-token prediction is the process in which a language model predicts the most likely next token based on the previously provided tokens. Many modern autoregressive language models use this approach to generate text.

## 18.2 How Does Next-Token Prediction Work?
The model receives an input sequence, processes its tokens, and calculates probability scores for possible next tokens. It selects or samples a token and repeats the process until the response is complete.

## 18.3 Token Probability
Token probability represents how likely a particular token is to be selected as the next token based on the preceding context. The model generates a probability distribution over its vocabulary.

# 19. Handling Imbalanced Datasets in Machine Learning

## 19.1 Imbalanced Dataset
An imbalanced dataset is a dataset in which some classes contain significantly more observations than others. For example, in fraud detection, normal transactions may be much more common than fraudulent transactions.

## 19.2 Why Is Class Imbalance a Problem?
A machine learning model trained on imbalanced data may become biased toward the majority class. It can achieve high accuracy while failing to identify important minority-class examples.

## 19.3 Techniques to Handle Imbalanced Datasets

### 1. Random Oversampling
Random oversampling increases the number of minority-class observations by duplicating existing examples. It helps balance the class distribution but may increase overfitting.

### 2. Random Undersampling
Random undersampling reduces the number of majority-class observations to make the dataset more balanced. It reduces training size but may remove useful information.

### 3. SMOTE (Synthetic Minority Over-sampling Technique)
SMOTE generates synthetic minority-class examples by interpolating between existing minority-class observations. It helps increase minority-class representation without simply duplicating records.

### 4. ADASYN
ADASYN generates synthetic minority-class examples, giving more attention to observations that are difficult to learn. It focuses on minority examples surrounded by more challenging regions.

### 5. Class Weighting
Class weighting assigns higher importance or penalty to errors involving minority classes during model training. It encourages the model to pay more attention to underrepresented classes.

### 6. Threshold Tuning
Threshold tuning changes the decision threshold used to classify predicted probabilities into classes. It can improve recall or precision depending on the application's requirements.

### 7. Ensemble Methods
Ensemble methods combine predictions from multiple models to improve classification performance. Methods such as Balanced Random Forest are specifically designed to work with imbalanced datasets.

## 19.4 Evaluation Metrics for Imbalanced Datasets

### Precision
Precision measures how many of the observations predicted as positive are actually positive.

### Recall
Recall measures how many actual positive observations the model correctly identifies.

### F1-Score
F1-score is the harmonic mean of precision and recall. It is useful when both false positives and false negatives matter.

### Confusion Matrix
A confusion matrix summarizes classification results using True Positives, True Negatives, False Positives, and False Negatives.

### ROC-AUC
ROC-AUC measures how well a classification model distinguishes between positive and negative classes across different classification thresholds.

### PR-AUC
Precision-Recall AUC summarizes the relationship between precision and recall across different thresholds. It is particularly useful when the positive class is rare.

# 20. Types of Neural Network Architectures

## 20.1 Artificial Neural Network (ANN)
An Artificial Neural Network is a computational model made up of interconnected artificial neurons arranged in layers. It learns patterns from data by adjusting weights and biases during training.

## 20.2 Convolutional Neural Network (CNN)
A Convolutional Neural Network is a deep learning architecture primarily designed to process grid-like data such as images. It uses convolutional filters to identify features such as edges, textures, shapes, and objects.

## 20.3 Recurrent Neural Network (RNN)
A Recurrent Neural Network is a neural network designed to process sequential data by maintaining information from previous steps. It uses recurrent connections to retain information about earlier inputs.

# 21. Recurrent Neural Networks (RNN)

## 21.1 Generic Representation of RNN
An RNN processes a sequence of inputs one step at a time while maintaining a hidden state that carries information from previous steps. The hidden state is updated at each time step using the current input and the previous hidden state.

## 21.2 How Does an RNN Work?
At every time step, the RNN receives a new input and combines it with the previous hidden state to calculate an updated hidden state. This allows the network to use information from earlier elements of a sequence when processing the current element.

## 21.3 Deep RNN
A Deep RNN consists of multiple recurrent layers stacked on top of each other. Each layer processes sequential information and passes its learned representations to the next recurrent layer.

## 21.4 Limitations of RNN
Traditional RNNs can struggle to learn long-term dependencies because information from earlier time steps may become difficult to retain. They also suffer from vanishing and exploding gradient problems during training.

# 22. Long Short-Term Memory (LSTM)

## 22.1 LSTM
Long Short-Term Memory is a special type of recurrent neural network designed to learn long-term dependencies in sequential data. It uses a memory cell and gating mechanisms to control which information should be stored, updated, or forgotten.

## 22.2 Why Do We Need LSTM?
Traditional RNNs may lose important information when processing long sequences. LSTM addresses this limitation by providing a mechanism to preserve useful information over longer time periods.

## 22.3 LSTM Gates

### Forget Gate
The forget gate decides which information from the previous cell state should be removed or retained. It helps the network discard information that is no longer useful.

### Input Gate
The input gate determines which new information should be added to the cell state. It controls how the network updates its memory.

### Output Gate
The output gate determines which information from the cell state should be used to produce the hidden state. It controls what information is passed to the next time step or layer.

## 22.4 Applications of LSTM
- Text generation and language modeling.
- Speech recognition.
- Time-series forecasting.
- Sentiment analysis.
- Sequential pattern recognition.

# 23. Natural Language Processing (NLP)

## 23.1 NLP
Natural Language Processing is a field of AI that enables computers to understand, interpret, process, and generate human language. It combines machine learning, deep learning, and linguistic techniques.

## 23.2 Named Entity Recognition (NER)
Named Entity Recognition is an NLP task that identifies and classifies important entities in text. Common entity categories include Person, Organization, Location, Date, Time, and Money.

## 23.3 Example of NER

Sentence: "Google hired Rahul in Delhi on 10 January 2026."

- Google → Organization
- Rahul → Person
- Delhi → Location
- 10 January 2026 → Date

NER is commonly used in document processing, information extraction, recruitment systems, and chatbots.
