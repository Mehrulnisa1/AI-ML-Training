# Streamlit

This folder contains my learning and practice work with Streamlit, a Python framework used to create interactive web applications.

## Running Streamlit

Learned how to set up and run Streamlit applications using the uv environment and Streamlit development server.

## Basic Streamlit Elements

Learned how to use `st.title()`, `st.header()`, `st.subheader()`, `st.text()`, `st.write()`, and `st.markdown()` to display and format content in a Streamlit application.

## Input Widgets

Learned how to take user input using `st.selectbox()`, `st.checkbox()`, `st.radio()`, `st.number_input()`, `st.text_input()`, and `st.date_input()`.

## Buttons and Messages

Learned how to create interactive buttons using `st.button()` and display success messages using `st.success()`.

## Layout

Learned how to organize a Streamlit application using `st.columns()`, `st.sidebar`, and `st.expander()`.

## DataFrames

Learned how to display tabular data in Streamlit using `st.dataframe()` and work with DataFrames inside a Streamlit application.

## HTTP Requests

Learned how to use the `requests` library to send HTTP requests from a Streamlit application, communicate with APIs, and work with API responses.

## Technologies Used

Python, Streamlit, Requests, and Pandas.

## Purpose

This folder contains my practice work for learning the fundamentals of Streamlit and building interactive Python web applications.
